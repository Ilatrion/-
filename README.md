# HotelManager — автономный сайт

**Открыть сайт: https://ilatrion.github.io/-/**

Сервер приложения, Node.js и аккаунт ChatGPT посетителю не нужны. Все функции выполняются непосредственно в браузере, данные сохраняются в его IndexedDB.

## Первый вход

1. Откройте сайт по ссылке. При первом запуске придумайте пароль администратора длиной от 12 символов и повторите его.
2. Логин администратора — `admin`. После создания базы придумайте PIN из 4–6 цифр, сохраните код восстановления.
3. Чтобы проверить гостя, выйдите из аккаунта и зарегистрируйте гостевой аккаунт. Затем войдите в него и создайте бронирование.
4. Выйдите из гостя и войдите в администратора в том же браузере: его уведомления содержат действия гостя.

Готовые пароли не публикуются. Аккаунты и брони прежней серверной версии автоматически не переносятся. На другом компьютере или в другом браузере будет отдельная новая база.

## Запуск совсем без интернета

Скачайте файл **index.html** из автономного архива и откройте двойным щелчком в Chrome или Edge. Все скрипты, фотографии, стили и QR-генератор включены внутрь этого файла. Интернет для скачанной версии не требуется.

GitHub Pages нужен только для первоначальной загрузки сайта по ссылке. Для гарантированной работы без сети используйте скачанный HTML. Не открывайте HTML в просмотрщике документов: выберите «Открыть с помощью → Chrome / Edge».

## Что работает

- Современный адаптивный интерфейс телефона и компьютера, светлая/тёмная темы, кнопка «Домой».
- 20 номеров, три категории, включая Стандарт для трёх гостей. Даты, ночи, цена, отель и контакты подставляются автоматически.
- Бронирование, изменение, отмена, заселение, переселение, выезд; уборка и ремонт.
- Дополнительные услуги, счета, учёт оплат и возвратов, учебная форма СБП/QR без перевода денег.
- Учебные роли, PIN, восстановление доступа, уведомления администратора, журнал действий, отчёты CSV/печать.
- Задачи, заметки, JSON-импорт/экспорт заметок, учебная проверка QR, руководства при первом входе.

## Где данные

Данные остаются в том браузере и по тому адресу, где вы работали. Вкладки одного браузера видят изменения после обновления (автоматическая проверка примерно каждые 15 секунд). Между компьютерами, разными браузерами, GitHub Pages и скачанным HTML автоматического обмена нет.

Не очищайте данные сайта, если хотите сохранить работу. В приватном режиме база может исчезнуть после закрытия окна. Экспорт администратора сохраняет деловые данные в JSON; этот экспорт не является полной резервной копией аккаунтов и не импортируется обратно автоматически.

Все данные доступны владельцу устройства через инструменты браузера. Локальное разделение ролей демонстрирует сценарии учебного приложения, но не заменяет серверную защиту. Настоящие деньги не переводятся. Камера необязательна; при ограничениях браузера доступен ручной ввод демонстрационного кода.

## Для разработчика

Посетителям ничего устанавливать не нужно. Для пересборки исходников разработчик использует Node.js 24:

```bash
npm ci
node scripts/build-offline.mjs
npm test
node tests/offline.test.mjs
```

Результат — единый файл `pages/index.html`. GitHub Actions собирает и публикует его при изменениях ветки main. `offline/` содержит локальное хранилище и первый запуск; правила размещения и платежей переиспользуются из `src/engine.mjs`. Старые серверные файлы сохранены как исходная реализация, но в автономной сборке сервер не запускается и сетевые запросы отсутствуют.

В проверках: 28 сценариев правил и прав плюс 8 проверок IndexedDB, локальных сессий, оплаты, конкурирующих броней и автономной сборки. Браузерные скриншоты в среде сборки недоступны; статические проверки не заменяют проверку внешнего вида на вашем устройстве.
