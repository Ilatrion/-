# Руководство пользователя

1. Откройте адрес сервера в браузере. Войдите с выданными учётными данными либо зарегистрируйте свою гостевую учётную запись. Создайте PIN, сохраните показанный код восстановления и ознакомьтесь с подсказками первого входа.
2. На главной выберите заезд, выезд, число гостей (1–3), категорию и бюджет. Стандарт также доступен для трёх гостей. Номера показываются с учётом занятости на даты.
3. Выберите номер. Проверьте автоматически подставленные контакты и параметры поездки. Укажите пожелания, подтвердите бронь. Откроется карточка проживания с датами, номером и счётом.
4. В «Моих бронированиях» открывайте свои поездки. Будущую бронь можно изменить или отменить. Оплаченную бронь отменяют после учёта возврата сотрудником. Заселение и выезд выполняет персонал.
5. Для учебной оплаты откройте счёт и выберите СБП/QR. В демонстрационной форме выберите результат платежа. Успех уменьшит остаток один раз; ошибка и отмена не изменят счёт. QR учебный, для банковского приложения не предназначен. Настоящие деньги не списываются.
6. В профиле можно изменить контакты и пожелания. Они подставятся в последующие брони. Изменения будущих бронирований также учитывают обновлённые контакты.
7. «Домой» возвращает на главную; тема переключается кнопкой солнца/луны. На телефоне основные разделы находятся в нижнем меню. При уходе с несохранённой формы появится предупреждение.
8. Если забыли PIN, после входа по паролю используйте код восстановления. Будет выдан новый одноразовый код. Не передавайте свой PIN и код другим людям.
9. Завершайте работу кнопкой «Выйти». Обычный гость видит только свои данные. Действия по бронированию, профилю и учебным платежам поступают в уведомления администратора.

Если сайт недоступен, проверьте, что сервер запущен и используется правильный адрес. При совместной работе все устройства должны обращаться к одному серверу. Изменения других пользователей появляются примерно за 15 секунд; можно обновить данные кнопкой интерфейса.
